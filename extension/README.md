## Installation & Quick Start

1. Open Chrome and navigate to `chrome://extensions/`.
2. Enable **Developer mode** in the upper-right corner.
3. Click **Load unpacked** and select the `extension` folder.
4. Navigate to any supported short-form video feed:
   - [TikTok](https://www.tiktok.com)
   - [YouTube Shorts](https://www.youtube.com/shorts)
   - [Instagram Reels](https://www.instagram.com/reels)
5. Open the studio via:
   - Floating edge trigger tab on the right edge
   - Keyboard shortcut: `Alt+S` (Toggle Studio) or `Alt+C` (Quick Copy Viral Script)
   - Clicking the extension icon in the toolbar
